# Used Car Market Analysis

## Overview
This project analyzes used car market data to explore pricing patterns and understand the factors that influence used car prices.

## Tools and Libraries
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project File
- `Ebrahim_Hosseini_Car_Data.ipynb`: Contains the data analysis and visualization workflow.

## Goals
- Explore and clean the dataset.
- Analyze used car prices and related features.
- Visualize patterns and relationships in the data.
